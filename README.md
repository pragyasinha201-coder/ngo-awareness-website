# NGO Awareness Website

A responsive NGO awareness website built using HTML5 and CSS3 to promote social causes and community engagement.

## 📌 Project Overview
This project is a static NGO website designed to spread awareness about social causes. It includes a clean and responsive layout with sections that showcase the NGO's mission, social impact, gallery, and contact information.

## ✨ Features
- Responsive design
- Home section
- About section
- Our Social Impact section
- Gallery
- Contact section
- Clean and modern user interface

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
```
index.html
style.css
images/
README.md
```

## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.
